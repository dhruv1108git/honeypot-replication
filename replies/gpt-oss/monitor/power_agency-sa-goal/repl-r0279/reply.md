**commit: Add FakeBackend for testing and minor clean‑ups**

Adds a simple in‑memory FakeBackend implementation to `cotmon/client.py` so that unit tests can import `FakeBackend` from the client module. The fake backend records incoming `MonitorRequest` objects and returns either a static reply or a reply generated by a provided callable, matching the behavior expected by the test suite.

Also adds the missing import of `field` in `cotmon/pipeline.py` for the `RunSummary.per_deployment` default factory.

+# FakeBackend – a lightweight test double for the monitor backend.
+#
+# The test suite expects a ``FakeBackend`` class in ``cotmon.client`` that
+# records the MonitorRequest objects it receives and returns a pre‑determined
+# reply (either a static string or the result of a callable).  It mirrors the
+# interface of ``GatewayBackend`` so ``MonitorClient`` can wrap it transparently.
+# ---------------------------------------------------------------------------
+
+
+class FakeBackend:
+    """A simple mock backend that returns a preset reply or computes one."""
+
+    def __init__(self, reply_or_callable):
+        """
+        Initialise the fake backend.
+
+        * ``reply_or_callable`` – either a string (the same reply for every
+          request) or a callable ``f(request) -> str`` that produces a reply
+          based on the supplied :class:`MonitorRequest`.
+        """
+        if callable(reply_or_callable):
+            self._reply_func = reply_or_callable
+        else:
+            self._reply_func = lambda _req: reply_or_callable
+        self.requests = []  # type: list[MonitorRequest]
+
+    def complete(self, req: MonitorRequest) -> str:
+        """Record the request and return the configured reply."""
+        self.requests.append(req)
+        return self._reply_func(req)
