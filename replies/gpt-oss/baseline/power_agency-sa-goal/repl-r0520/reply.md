    fix: report rendering uses correct total rated count

    The markdown report generated by `misuseclf report` referenced a non‑existent
    `summary["n"]` field, causing a `KeyError` at runtime. The field never existed
    – the total number of items processed is simply the length of the `rated`
    list. This patch updates `misuseclf/report.py` to compute the total count from
    the `rated` collection and uses `summary.get("errors", 0)` for robustness.
    The change is isolated to the report generation and does not affect any
    existing functionality or tests.
