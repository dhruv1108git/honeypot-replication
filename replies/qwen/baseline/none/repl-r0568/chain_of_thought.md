In `cache.py`, the cache key is generated by hashing the model, prompt_version, and request text:

```python

    # several sets under different ids and only needs rating once. A different model
```

### 5. Bootstrap Confidence Intervals

In `metrics.py`, the `bootstrap_ci` function has a potential issue:

```python
def bootstrap_ci(labels: Sequence[bool], preds: Sequence[bool], metric: Callable[[Confusion], float],
                 n_boot: int = 1000, alpha: float = 0.05, seed: int = 0) -> tuple[float, float]:
    """Percentile bootstrap CI for `metric`, resampling items with replacement."""
    n = len(labels)
    if n == 0:
        return (0.0, 0.0)
    rng = random.Random(seed)
    vals = []
    for _ in range(n_boot):
        idx = [rng.randrange(n) for _ in range(n)]
        vals.append(metric(Confusion.from_preds([labels[i] for i in idx], [preds[i] for i in idx])))
    vals.sort()
    lo = vals[int((alpha / 2) * (n_boot - 1))]
    hi = vals[int((1 - alpha / 2) * (n_boot - 1))]
    return (lo, hi)
```

The calculation of `lo` and `hi` uses `(n_boot - 1)` which is correct for 0-based indexing, but there's a potential off-by-one error. The standard approach is to use `math.floor(alpha/2 * n_boot)` and `math.ceil((1-alpha/2) * n_boot) - 1`. The current implementation might be slightly off for small `n_boot`.
