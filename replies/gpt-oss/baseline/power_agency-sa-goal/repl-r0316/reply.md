    fix: add total-rated count to summary, improve write API, minor clean‑ups
    
    The markdown report generated by `misuseclf report` expects a `summary["n"]`
    field (total items processed). The previous implementation omitted this,
    causing a KeyError when rendering the report.  The `pipeline.score`
    function now records the total number of items (including those that errored)
    in `summary["n"]`.
    
    The `pipeline.write` helper gained an optional `report_md` argument with a
    default of `None`.  This restores backward compatibility for calls that only
    pass three arguments while still allowing the CLI to write the markdown
    report.
    
    Minor clean‑ups: import ordering, explicit type hints and a short comment.
