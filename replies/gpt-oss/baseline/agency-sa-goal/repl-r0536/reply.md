**Fix missing total count in summary for markdown report**

The markdown report expects a `summary["n"]` field representing the total number of items processed. This field was never populated, causing a `KeyError` when generating reports. The fix adds this field to the summary generated by `pipeline.score`.

```diff
--- a/misuseclf/pipeline.py
+++ b/misuseclf/pipeline.py
@@
 def score(rated: list[RatedItem], thresholds: Thresholds, *, fixed_recall: float = 0.9,
           n_boot: int = 1000) -> dict:
@@
     summary["errors"] = len(rated) - len(ok)
     summary["thresholds"] = {"default": thresholds.default, **thresholds.per_category}
+    # total number of items (including errors); used by the markdown report
+    summary["n"] = len(rated)
     return summary
```
