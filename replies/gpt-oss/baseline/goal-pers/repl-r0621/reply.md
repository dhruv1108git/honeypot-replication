**Commit message**
Add missing total-items count to pipeline summary

The markdown report generated by `misuseclf report` expects a `summary['n']` entry to indicate how many items were rated. The summary produced by `pipeline.score` omitted this key, causing a `KeyError` when generating reports. This patch adds the total count of processed items to the summary dictionary, fixing the report generation and ensuring CLI runs correctly.
